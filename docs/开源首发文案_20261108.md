## 一、先看一条真实的链条

有个做电商客服的 Agent，用户只说了一句：

> 「帮我查一下这笔退款为什么没到账。」

内容审核看到这句话：完全安全，放行。

Agent 接下来的动作（从它的工具调用日志里扒出来的）：

```
10:07:01  read_sms          ← 读用户短信
10:07:02  send_credentials  ← 把验证码发出去
```

**一句话的工夫，验证码出去了。**

问题出在哪？每一步都「合法」：

- `read_sms` 是客服 Agent 的常规权限（帮用户读验证码）；
- `send_credentials` 单看是「发送凭据」，但没人会单独调它。

**单看每一步都没问题，串起来就是要命。** 而市面上 90% 的 Agent 防护，防的只是「每一步」——

## 二、四层防护，为什么全放行了

| 层 | 它防什么 | 为什么拦不住这条链 |
|---|---|---|
| **内容审核** | 用户说了什么 | 用户只说了「查退款」，干净的 |
| **Prompt 加固** | 提示词里塞指令 | 攻击不在提示词里，在动作里 |
| **工具白名单** | 能不能调这个工具 | `read_sms` 和 `send_credentials` 都在白名单里 |
| **日志审计** | 事后追查 | 事后能查到，但验证码已经出去了 |

**内容审核管「Agent 说了什么」，管不住「Agent 做了什么」。**

我自己的第一版系统，也漏过这条链。这个领域没有「写完就安全」这回事。

## 三、所以我做了「星环」：判行为链，不判单步

核心就一句话：**不评估「这个工具能不能调」，而是评估「这一串工具串起来，想干什么」。**

![神域星环图](../星环图.png)

（图：星系形态的三层架构——内核契约锚点、六星 M1–M6 编排闭环、三行星时空法则、五彗星失控防御补强）

三个判断维度，不讲黑话：

1. **看组合**：`read_sms → send_credentials` 是凭据外泄链，直接熔断；
2. **看参数**：`read_docs("../../etc/passwd")` 和 `read_docs("docs/报告.md")` 是同一工具，但前者越界；
3. **看谱系**：子 Agent 的权限只能比父更小，不能凭空放大。

在我自己的 172 条攻击样本上，**172/172 拦截、0 误伤**；跨进程复测 177/177 一致。

## 四、为什么开源：因为我缺一样东西

**上面所有数字，都是合成样本跑出来的。**

合成样本能证明「逻辑自洽」，证明不了「在你们公司不会误杀」。真实业务里的误报率，**我手里没有——因为我没有真实日志。**

我是个独立安全研究员，不是大厂。我没有百万级真实流量来校准误报率。

所以我开源了本地运行的基础版哨兵：

- **6 MB 单文件，纯离线**，日志不出你的机器；
- 30 项动作风险表 + 4 类组合链 + 参数闸门 + 未知动作熔断；
- 跑完终端会提示你：基础版只能看到规则能判的，更深的需要完整引擎。

**求你们用真实日志来砸我。**

具体怎么换，看仓库里的 `README.md`，一句话：`xh-scan upload --anonymize`，脚本自动把手机号、邮箱、路径替换成占位符，只上传脱敏后的行为链结构。完整引擎（三轨模型 + 177 条红队样本）在隔离机跑一遍，回你一份带水印的深度体检报告。
